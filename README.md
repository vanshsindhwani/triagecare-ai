# TriageCare AI

Intelligent Clinical Intake & Semantic Symptom Triage Portal built with React, Node.js Express, MongoDB, Socket.IO, and a Vector Space Model (TF-IDF & Cosine Similarity) NLP Engine.

## Tech Stack
- **Frontend**: React 18, Vite, Tailwind CSS
- **Backend**: Node.js, Express.js, Socket.IO
- **Database**: MongoDB (Mongoose ORM)
- **NLP Engine**: Vector Space Model (TF-IDF & Cosine Similarity)

## Getting Started

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Run Development Server**:
   ```bash
   npm run dev
   ```

3. **Build for Production**:
   ```bash
   npm run build
   ```
